# Job-Application Agent — Checkpoint-1 Demo

Minimal React demo showing the planning UI for a resume optimization agent.

Quick start

1. Install dependencies

```bash
npm install
```

2. Run development server

```bash
npm run dev
```

Open the server URL shown by Vite https://mukesh-219.github.io/job-application-agent/

Files of interest

- `src/App.jsx` — main UI component (planning layer)
- `src/main.jsx` — React entry
- `index.html` — app root
